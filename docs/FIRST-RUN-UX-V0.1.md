# First-Run UX V0.1

Commands:

- `tivor version` — binary, platform, schema, and registry versions.
- `tivor doctor` — local-only observation; no provider network execution.
- `tivor doctor --provider-path` — explicit experimental governed provider-path execution.

The first-run output must state: what is measured, what is not measured, that results remain local unless explicitly exported, that no credentials are needed, the supported macOS arm64 platform, required provider coverage, optional unsupported providers, and that provider-path evidence is not a provider-health verdict.
