# Web Scanner Measurement Backlog

This is post-Beta backlog, not Slice 10 implementation.

WEB-CAPABLE: bounded HTTPS timing/status class, browser DNS/connect/TLS aggregates exposed by permitted timing APIs, challenge/incomplete semantics, and consented coarse IP-family observations.

LOCAL-PROBE-ONLY: raw DNS stage sampling, direct TCP/TLS handshakes, route/default-interface observation, TUN-like interface observation, system certificate validation detail, resets, and deterministic local public export.

Browser security boundaries must never be bypassed to imitate local-probe parity.
